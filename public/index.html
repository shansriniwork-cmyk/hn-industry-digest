Hacker News Industry Digest

Top 5 Hacker News stories, refreshed once a day, each with a "why this matters" summary for the industry you choose below.

    Stories via the official Hacker News API (no key required). The top-5 list refreshes at most once per calendar day (cached in this browser via localStorage). Summaries are cached per story + industry, so switching the dropdown re-uses any summary already generated today. Summaries are generated by this site's server (/api/summarize), which keeps the Groq API key private and calls the LLM.
